# GC Tech API (Python)

Módulo de bookings em FastAPI + SQLAlchemy + SQLite. Projeto de treino com dados fictícios.

## Rodar
```
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
uvicorn app.main:app --reload
```
Documentação interativa: http://127.0.0.1:8000/docs

## Testes
```
pytest
```
